#### MCP iPhone

Программа для Windows и Mac, которая возвращает на iPhone банковские приложения, пропавшие из российского App Store: Сбербанк Онлайн, Т-Банк, Альфа-Банк, ВТБ и ещё пару десятков сервисов вроде VK, Авито и RUTUBE. Телефон подключается к компьютеру кабелем, вы входите под своим Apple ID, выбираете приложение, и оно ставится с обычной подписью Apple. Джейлбрейк не нужен.

Приложения пропадают, когда Apple убирает их из российского App Store. Если вы удалили банк с телефона, сбросили iPhone или купили новый, обратно через App Store его уже не поставить, хотя в покупках вашего Apple ID оно по-прежнему числится. Программа как раз этим и пользуется, поэтому ставит только то, что когда-то было на вашем аккаунте.

Первая установка бесплатная, дальше 100 ₽ за приложение, подписки нет.
